MIKO Knowledge

Личный инструмент владельца для сохранения и изучения материалов: ссылка из Telegram, получение доступного текста, архивирование и отдельный аналитический разбор.

Google Drive используется для хранения исходников, аналитических документов, PDF и каталога. Передачу и проверку файлов выполняет rclone. Смысловой анализ выполняется через Codex / OpenAI.

Инструмент предназначен для личного использования владельцем, а не для регистрации сторонних пользователей. Эта страница содержит только описание приложения; она не предоставляет доступ к библиотеке.
